# JINTEC 공식 사이트 리뉴얼 (상세 정보 보존 버전)

`index.html`을 열면 메인 사이트를 볼 수 있습니다. 별도의 서버나 빌드 과정이 없는 HTML/CSS/JS 정적 웹사이트입니다.

## 독립 페이지
- `history.html`: 기존 연혁 2010~2021년 월별 납품 내역 전체
- `certifications.html`: 기존 인증현황 특허 원본 이미지
- `location.html`: 오시는 길, 주소, 연락처, 지도 및 네이버 지도 링크
- `sub2_1.html`: 항온항습 챔버 전체 상세 정보
- `sub2_2.html`: 항온 챔버 전체 상세 정보
- `sub2_3.html`: 열충격 시험기 전체 상세 정보
- `sub2_4.html`: 건조기 전체 상세 정보
- `sub2_5.html`: 항온 룸 챔버 전체 상세 정보

제품 페이지는 제공하신 기존 사이트 HTML의 내용을 그대로 추출해 옵션사항·제품 특징·제품 이미지·도표·사양표를 보존했습니다. 원본에서 항온 챔버 설명과 사양표 일부, 건조기 사양표 모델명 등에 차이가 있어 기존 데이터 그대로 유지했습니다. 실제 게시 전 제품 사양을 확인해 주세요.
